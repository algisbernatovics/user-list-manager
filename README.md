# User List Manager

A small PHP class exercise for storing user records and selecting a special user from the list.

## Overview

A small PHP class exercise for storing user records and selecting a special user from the list.

## Features

- Accepts a single user string or an array of users.
- Filters invalid entries by pattern.
- Sorts stored users and returns a selected value from the highest-ranked entry.
- Includes PHPUnit tests.

## Tech Stack

- PHP
- Composer
- PHPUnit

## Project Structure

- `app/Users.php` - user collection logic
- `tests/UserTest.php` - test cases for expected behavior

## Getting Started

Install dependencies and run tests:

```bash
composer install
vendor/bin/phpunit
```
